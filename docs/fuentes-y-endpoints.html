02  Cómo se convierte el dato en alerta

El motor de umbrales

El núcleo de SIMPAC es comparar los datos en tiempo real contra umbrales por zona. Dos entradas cuantitativas (lluvia horaria de SENAMHI y caudal de ANA, que ya trae sus propios umbrales) más el aviso oficial de SENAMHI producen un nivel de alerta que alimenta el titular, el mapa y la notificación push.

03  SENAMHI

Estaciones, datos horarios y avisos

Inventario de estaciones · HTML con JSON embebido

GET https://www.senamhi.gob.pe/mapas/mapa-estaciones-2/?dp=cajamarca

Trae un array JS PruebaTest con ~90 estaciones de Cajamarca:

{"nom":"AUGUSTO WEBERBAUER","cate":"MAP","lat":-7.1675,"lon":-78.49309,
 "ico":"M","cod":"107028","estado":"REAL"}
  • ico: M meteorológica · H hidrológica.
  • estado: REAL (convencional 07/13/19h) · DIFERIDO · AUTOMATICA (telemetría horaria).
  • Claves: Weberbauer 107028, Granja Porcón 107002; automáticas con código hex (Cutervo 4726A602, etc.).

Datos horarios en tiempo real por estación · sin CAPTCHA

GET https://www.senamhi.gob.pe/mapas/mapa-estaciones-2/map_red_graf.php
    ?cod={cod}&estado={estado}&tipo_esta={M|H}&cate={cate}&cod_old={cod_old}

Devuelve HTML con la serie de Highcharts embebida (últimas ~48 h): xAxis.categories = timestamps YYYY/MM/DD - HH; series[].data = Precipitación (mm/hora) y Temperatura (°C) en estaciones meteorológicas automáticas (nivel/caudal en hidrológicas). Es la entrada directa del umbral de lluvia.

Avisos meteorológicos · tabla HTML

GET https://www.senamhi.gob.pe/?p=aviso-meteorologico

Columnas: Aviso · Nro (emitido/vigente) · Emisión · Inicio · Fin · Duración · Nivel. Nivel = AMARILLO / NARANJA / ROJO. Detalle: ?p=aviso-meteorologico-vigente&a={año}&b={id}&c=00&d=SENA. Filtrar por títulos de "SIERRA NORTE" / Cajamarca.

Mapas de anomalías · IDESEP / GeoNetwork

Catálogo geoespacial en idesep.senamhi.gob.pe/geonetwork/srv/api/… (CSW + REST). Shapefiles dentro de .zip → GeoPandas → GeoJSON → Leaflet. Detalle en la pre-documentación general.

GET .../geonetwork/srv/eng/csw?service=CSW&request=GetRecords&elementSetName=summary&startPosition=N
    → catálogo paginado (dc:identifier = uuid, dc:title = título)
GET .../geonetwork/srv/api/0.1/records/{uuid}
    → página del registro con el enlace al .zip (en /attachments/)

Implementado (22 sep): conector backend/connectors/idesep.py y cargador backend/mapas/cargar_fen.py. Cargados en la tabla mapa (variable='FEN') los 5 mapas de anomalías de precipitación de eventos El Niño: 82-83, 97-98, Costero 2017, Costero 2023 y 2023-2024 (polígonos con la propiedad RANGO). La muestra mensual de anomalías por estación va con variable='precipitacion'. Los GeoJSON de SENAMHI ya no se suben al repo (el archivo subido antes sigue en el historial de git) y la tabla mapa es de lectura pública, siempre con atribución a SENAMHI/IDESEP.

Límite: el histórico mensual tabular (pestaña "Tabla", desde 2021-10) está protegido por CAPTCHA (Cloudflare Turnstile). No se automatiza ni se evade; para histórico usar PISCO o descarga oficial. El gráfico horario de las últimas 48 h sí es libre.

04  ANA — Autoridad Nacional del Agua

Caudales de ríos con umbrales

App ASP.NET (SNIRH / Observatorio ONRH); los datos salen de web services .asmx vía POST que devuelven JSON.

Reporte nacional de caudales · el más valioso

POST https://snirh.ana.gob.pe/onrh/ServicioReportes.asmx/ReporteNacionalCaudal
   (página: https://snirh.ana.gob.pe/onrh/Reportes.aspx?R=PRIOS)

Array JSON, un objeto por estación hidrológica:

{ "DEPARTAMENTO":"Cajamarca", "RIO":"Cañad", "ESTACION":"Cañad",
  "VALOR":"0.25", "UNIDADMEDIDA":"m³/s",
  "UALERTA":"78.58", "UEMERGENCIA":"122.99",
  "TENDENCIA":"Descendente", "HORA":"20:00",
  "LONGITUD":"-78.9973", "LATITUD":"-6.649", "OPERADOR":"SENAMHI" }
  • Cajamarca: estaciones "Cañad" (río Cañad) y "Yónan Gore" (río Jequetepeque); Mashcón y Namora en el mapa.
  • Alerta directa comparando VALOR contra UALERTA / UEMERGENCIA. JSON limpio, sin CAPTCHA.

Capas temáticas (mapa) · visor por cuenca

Visor:   https://snirh.ana.gob.pe/VisorPorCuenca/?IdVar={N}
Puntos:  POST …/VisorPorCuenca/ServicioGeneral.asmx/ListarMapaGEO
         → [{I:id, D:nombre, O:tipo, C:[lon,lat]}]

IdVar útiles: 228 ríos monitoreados · 46 embalses · 39 emergencias hídricas · 106 SAMAQ (activación de quebradas / huaycos) · 220 puntos críticos. Emergencias (39) y SAMAQ (106) son ideales para cruzar con reportes ciudadanos.

05  CENEPRED — SIGRID

Capas de peligro y riesgo (referencia)

Geoportal sigrid.cenepred.gob.pe/sigridv3/; visor con API JS de ArcGIS 3.41.

Visor de escenario: /sigridv3/mapa?id={idEscenario}&boletin={n}
Config:  POST /sigridv3/entorno/traer  →  { extension, mapa_base, shape(WKT),
         capas_activas: "cartografiaPeligros=[…]; cartografiaRiesgos=[…];
                         elementosExpuestos=[…]; …" }

Las capas se sirven por ArcGIS REST (MapServer / FeatureServer) — consumibles con identify/query o como WMS. Hay muchos escenarios de riesgo de Cajamarca (p. ej. deslizamiento en Contumazá, fuente INGEMMET). Uso en SIMPAC: capa de contexto de riesgo y para el cruce (¿el reporte cae en zona de peligro alto?). No es tiempo real.

06  IGP

Índice Costero El Niño (ICEN)

http://met.igp.gob.pe/datos/ICEN.txt        # oficial (ENFEN 2024)
http://met.igp.gob.pe/datos/ICEN_91_20.txt  # base 1991-2020 (= base NOAA)
http://met.igp.gob.pe/datos/ICENr.txt       # ITCEN: valor reciente/provisional
http://met.igp.gob.pe/datos/EC.txt          # índices E y C (Takahashi)

Texto plano: comentarios con %, luego yy mm ICEN (mensual desde 1950). Actual: 2026-05 = +1.98 (cálidas). Categorías para el semáforo: neutro (−0.4, 0.4) · cálido débil [0.4, 1.0) · moderado [1.0, 1.7) · fuerte [1.7, 3.0) · extraordinario ≥ 3.0.

HTTP-only (Apache 2.2, puerto 80). Una web HTTPS no puede hacer fetch a http (mixed content) → el backend debe descargar/proxyear el archivo y cachearlo a diario.

07  NOAA — Climate Prediction Center

ONI — contexto ENSO global

https://www.cpc.ncep.noaa.gov/data/indices/oni.ascii.txt   # ONI mensual
https://www.cpc.ncep.noaa.gov/data/indices/wksst8110.for   # TSM semanal Niño 1+2/3/3.4/4

ONI en texto plano, columnas SEAS · YR · TOTAL · ANOM (ANOM = ONI, base 1991-2020). HTTPS, sin auth, la fuente más fácil de ingerir. Actual: JJA-2026 = +1.80 (El Niño).

08  ENFEN

Estado de alerta El Niño Costero

Sitio enfen.imarpe.gob.pe sobre WordPress (enlaces de descarga ?wpdmdl=). Vías de adquisición:

GET https://enfen.imarpe.gob.pe/wp-json/wp/v2/posts?per_page=10&_fields=id,date,title,link
    # comunicados; PDFs vía ?wpdmdl={id}

Aporta el estado cualitativo de alerta (Vigilancia / Alerta) de El Niño/La Niña Costero. El valor numérico del índice ya se obtiene del IGP (sección 06), que es la fuente operacional definida por ENFEN.

Límite de la sesión: ENFEN no fue accesible desde este entorno (DNS/red: navegación denegada y curl con código 000). Es un bloqueo del entorno, no del sitio; reintentar desde el servidor de producción.

09  Uso responsable

Buenas prácticas de adquisición

  • Caché + rate limit: guardar cada respuesta y espaciar las peticiones; ninguna de estas fuentes es de alta frecuencia (se actualizan por hora). No martillar los servidores del Estado.
  • User-Agent identificable y revisión de términos de uso y robots.txt de cada sitio.
  • Backend como proxy: obligatorio para IGP (HTTP-only) y conveniente para todos (evita CORS y oculta el origen al cliente).
  • Conectores aislados con pruebas: las APIs internas y el scraping cambian sin aviso; un módulo por fuente contiene el daño.
  • Atribución visible de la fuente en cada dato mostrado.
  • Sin evadir CAPTCHA: el histórico tabular de SENAMHI queda fuera de alcance por diseño.

10  Pendientes

Limitaciones de esta pasada

  • ENFEN: inaccesible desde el entorno de captura; validar wp-json desde producción.
  • SENAMHI histórico: CAPTCHA en la tabla mensual; para series largas evaluar PISCO / descarga oficial.
  • CENEPRED: falta capturar la URL exacta del MapServer de cada capa (activar una capa en el visor y leer la petición ArcGIS).
  • ANA: confirmar el reporte de embalses y el formato del payload POST (parámetros) de cada .asmx.
  • Verificar todos los endpoints en temporada de lluvias (dic–abr), cuando los umbrales realmente disparan.
